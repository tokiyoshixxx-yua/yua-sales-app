スナックゆあの大作戦 売上管理アプリ（Ver.8）

1. GitHubで新しい公開リポジトリ yua-sales-app を作成（既存の公式ホームページのリポジトリは編集しない）。
2. ZIPを展開して index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png の5ファイルを新規リポジトリの直下へアップロードしてCommit。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. Pagesに表示されたURLをiPhone Safariで開く → 共有 → ホーム画面に追加 → Webアプリとして開く → 追加。
5. 表示名は「ゆあ大作戦」。名称はホーム画面に追加する直前に変更できる。

注意：現在のアイコンは紫地にYの仮デザイン。本来の「スナックゆあの大作戦」ロゴの画像はこの配布物に含まれていません。
注意：GitHub Pagesではアプリ画面自体はインターネットに公開されます。ログイン認証なし。
注意：顧客名と売上は端末内に保存され、同期やサーバーバックアップはありません。CSV/JSONをGitHubに絶対アップロードしないでください。
注意：本アプリは試作品です。料金・端数処理・操作・保存と復元の実機確認が済むまで、正式な売上台帳の代わりに使わないでください。
